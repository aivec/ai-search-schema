# v1.3.0

**Release date**: 2026-08-02

## Fixed

- Fixed a fatal error on Product schema pages when WooCommerce is not active
- Fixed llms.txt being HTML-escaped, which broke Markdown quotes and apostrophes
- Fixed llms.txt redirecting to a trailing-slash URL instead of serving directly

## Security

- Blocked PHP object injection when restoring serialized product meta

## Changed

- Raised the minimum supported WordPress version to 6.5
- Confirmed compatibility with WordPress 7.0
- Added X-Content-Type-Options: nosniff to the llms.txt response
- Consolidated translation templates into a single aivec-ai-search-schema.pot
